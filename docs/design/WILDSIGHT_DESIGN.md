# WildSight 见野移动端设计系统 v1.0

## 品牌定位

随身携带的个人自然博物馆与城市自然观察手记：安静、可信、编辑式、轻纸张感。页面服务于“遇见—认识—收录—回看”，不是养护工具或数据仪表盘。

## Token

- 浅色：纸张背景 `#F5F3EF`，次级背景 `#EDF0E9`，表面 `#FCFCF8`，正文 `#1E251F`，辅助文字 `#697269`，克制自然绿 `#4F6955`。
- 深色：深炭灰绿背景 `#151A18`，表面 `#29332D`，暖白正文 `#F0F4EE`，灰绿辅助文字 `#BBC6BC`，自然绿 `#9BD4A5`。
- 字体：系统 serif 用于展示标题，sans-serif 用于正文，monospace 仅用于观察编号；保持现有 `AppTypography` 层级。
- 间距：4/8/12/16/24/32/48vp；页面水平留白 20vp；圆角 12/16/24/28vp。

## 页面和组件

摄影是“遇见”的主载体；物种详情先显示个人相遇，后显示审核知识。卡片只用于必要的轻承载面，靠描边与留白分层，不用重阴影。设置页可使用分组与系统图标方块，但必须与其他页面共用 Token。功能图标使用 SymbolGlyph；返回、空状态、知识卡、轻量元信息均保持单一语言。

## 导航、无障碍与禁止项

底部 `HdsTabs` 使用项目原有的绿色选中态和灰绿色未选中态：浅色为 `#2F8F5B` / `#69756C`，深色为 `#9BD4A5` / `#A5B0A7`；不得改回系统默认蓝色，除非产品明确提出变更。正文与背景保持清晰对比，触控行使用完整宽度，小屏滚动预留底栏空间。禁止满屏绿色、强渐变、玻璃拟态、霓虹、卡通植物、Material Dashboard、堆叠大卡片、混用图标风格，以及 CapKnow 的内容或布局。
