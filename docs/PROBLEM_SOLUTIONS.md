## 2. 本轮已实施：发现页与识别入口

### 2.1 拍照识别无法正常唤起摄像头（已实施）

涉及：

- `entry/src/main/ets/services/PhotoService.ets`
- `entry/src/main/ets/App.ets`
- `entry/src/main/ets/pages/discovery/DiscoverPage.ets`
- `entry/src/main/module.json5`

本轮处理：

1. 在打开 CameraPicker 前请求模块已声明的 `ohos.permission.CAMERA`；拒绝时回到发现页并保留相册识别。
2. 按本机 SDK 运行时要求用对象字面量创建 `PickerProfile`，并通过应用沙箱文件 URI 设置 `saveUri`，避免对只读属性做实例赋值。
3. 相机返回 URI 后继续调用既有 `startIdentification(photoUri)`，没有重写识别链路。

真机设备 `2UCUT23C27028737` 已验证：发现页拍摄区 → 系统相机 → 拍照预览 → 确认 → “识别结果”，照片能够显示。

没有引入持续相机预览、额外权限或新的相机框架。

### 2.2 “从一次相遇开始”改为正方形拍摄区域（已实施）

当前发现页空状态是横向文字卡片。目标是改成 1:1 正方形拍摄入口：

- 使用现有主题 Token 和相机系统图标；
- 点击整个区域触发 `onTakePhoto()`；
- 保留“从相册识别”；
- 有 `heroPhotoUri` 时继续显示已选照片预览；
- 不引入外部图片或大面积新插画；
- 不让区域挤压底部 Tab 或产生横向溢出。

发现页空状态和已选照片预览均使用 1:1 区域；点击整个区域触发 `onTakePhoto()`，相册识别按钮仍保留。

### 2.3 移除发现页“最近发现”（已实施）

删除发现页中的完整“最近发现”区块，包括列表、空状态、查看图鉴和点击跳转；同步清理 `DiscoverPage` 的无用 Prop、回调、方法和 import，以及 `App.ets` 的无用传参。没有删除图鉴页的相遇数据。

### 2.4 把识别建议移到发现页（已实施）

当前“识别更准确的小建议”位于 `AtlasPage.ets` 的 `GuidanceCard`。目标：

- 从图鉴页移除；
- 在发现页的拍摄区域和按钮之后展示；
- 保留“尽量拍清叶片、花朵或整体形态”等文案；
- 可提取到 `components/`，但不能在两个页面各保留一份。

建议卡片现位于发现页拍摄区域和识别按钮之后，图鉴页不再保留副本。

### 2.5 统一二级页面标题栏（已修复并真机验收）

`我的图鉴`、识别结果、相遇详情、物种详情和设置详情页共用 `SecondaryPageHeader`。该组件已按日月工程 `SettingsDetailHeader` 的实际代码统一为：56vp 栏高、44vp 圆形按钮、23vp 左箭头、12vp 按钮标题间距和 22fp Bold 标题。返回按钮不使用描边或阴影，浅深色继续读取见野 `AppColors`。

参考图的统一结构：系统状态栏下方是一块稳定的顶部表面；左侧为圆形返回按钮，页面大标题紧随其后并垂直居中；正文从标题栏下方开始。参考的是布局、层级和尺寸关系，不复制截图里的“多设备协同”等业务内容。

统一范围：

- 设置内全部详情页；
- 我的图鉴；
- 物种详情；
- 相遇详情；
- 识别结果；
- 后续新增的所有二级页。

解决要求：

1. 继续统一使用 `entry/src/main/ets/components/SecondaryPageHeader.ets`，页面不得各自实现另一套返回按钮和标题栏。
2. 标题栏和 Scroll/List 使用纵向兄弟结构，不随正文滚走，也不依赖绘制层级覆盖正文。
3. 标题栏高度、内容间距和系统安全区统一由 `AppDimensions` 管理。
4. 标题栏左右 16vp；返回按钮使用 44vp 圆形点击区域，23vp 图标居中。
5. 标题使用 22fp Bold 单行文本，与返回按钮垂直居中；超长标题省略。
6. 正文不能被标题栏遮挡，也不能因为页面自身 padding 再产生一层重复顶部空白。
7. 浅色和深色均使用对应的 `AppColors` 实色背景，不引入新的图片或路由模型，不影响底部 `HdsTabs`。

### 2.6 一级图鉴标题位置不一致（已修复并真机验收）

问题：图鉴页顶部标题“图鉴”与发现、设置一级页的标题起点或顶部间距不一致。

解决要求：

- 图鉴、发现、设置三个一级页统一使用 `PageTitle` 和同一组 `AppDimensions`；
- 标题左边缘统一为 16vp，使用同一个 56vp 标题行；
- 字号、行高、粗细和副标题间距保持一致；
- 检查 `AtlasPage` 外层容器是否与 `PageTitle` 重复添加 padding 或 top inset；
- 浅色、深色和不同屏幕宽度下保持相同视觉基线。

三个一级页现在共用同一 `PageTitle` 标题行、22fp Bold 字体和 16vp 起点；图鉴、发现的副标题位于标题行下方，设置页只显示标题。图鉴 `Scroll` 使用 `minHeight: 100%` 防止短内容被垂直居中，设置页的固定标题容器也复用同一标题块高度。

2026-08-17 已在设备 `2UCUT23C27028737` 对照图鉴、发现、设置三个一级页，标题左边缘和纵向起点一致。

### 2.7 二级页停止滚动后标题栏背景消失（已修复并真机验收）

旧实现通过 `scrollOffset > 1` 控制背景 opacity 和 blur。页面的 `onScroll` 参数不应被用于控制背景显隐；滚动停止时状态可能回到 0，使标题栏背景透明或消失。本轮已移除这条依赖。

解决要求：

1. 标题栏背景永久使用当前主题的实色页面背景，opacity 始终为 1。
2. 不再使用滚动状态控制背景显隐、透明度或 blur；代码已落实。
3. 当前不再根据滚动状态增加阴影或分隔线，避免视觉状态抖动。
4. 页面从 Stack 覆盖结构改为 Column 纵向结构：`SecondaryPageHeader` 固定在上，Scroll/List 使用剩余空间。
5. 正文只滚动自身区域，不能进入或覆盖标题栏的绘制区域。
6. 验收覆盖初始状态、滚动中、停止滚动、回到顶部、快速滚动和深色模式；任何状态下背景都不能消失。

2026-08-17 已在设备 `2UCUT23C27028737` 对物种详情执行向上快速滚动并等待停止；标题文本坐标保持 `[243,199][1170,286]`，标题栏背景和返回按钮均保持可见。深色模式仍应作为发布前回归项重复检查。

## 3. 已知风险

### 照片 URI 长期可读性

当前只保存 PhotoPicker/CameraPicker 返回的 URI，没有应用沙箱媒体副本。应用重启、系统清理或权限变化后的长期可读性尚未完整验证；后续应设计可恢复的媒体资产策略，不要在本轮 UI 修复中擅自扩大范围。

### 签名配置

`build-profile.json5` 含本机签名路径和明文凭据风险。正式交付前迁移到本机安全配置并轮换已暴露凭据；任何普通页面或知识库任务不得复制、输出或修改这些内容。

### 生产与真机状态

历史服务器健康检查和真机安装记录只代表记录日期，不代表当前重新验证。未联网、无 HDC 设备时必须如实报告。
